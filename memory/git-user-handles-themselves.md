On the ForgeSeries-CLK project the user does all git work themselves.

**Why:** They explicitly said "don't handle git... I'll do it all myself" after the
multi-instance work landed.

**How to apply:** Finish the code/build/test work and stop there. Don't commit,
branch, or push, and don't offer to — leave the working tree for them to handle.
