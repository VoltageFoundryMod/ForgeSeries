Across the ForgeSeries repos the user does all git work themselves.

**Why:** They said so explicitly on ForgeSeries-CLK ("don't handle git... I'll do
it all myself"), and the same convention applies here.

**How to apply:** Finish the code/build/test work and stop there. Don't commit,
branch, or push, and don't offer to — leave the working tree for them.
